# Forest-Fires
M. Tech Thesis titled "Evaluating Forest Fire Vulnerability and Climate Drivers in Northeast India using Remote Sensing and  Advanced Machine Learning Techniques" #ML #GEE #Python

For Forest Fire Susceptibility mapping, feature importance is evaluated using ML algorithms, RF and XGB. Raster values of different factors are extracted at available fire points and randomly generated non-fire points, and this data is split for training and testing.
